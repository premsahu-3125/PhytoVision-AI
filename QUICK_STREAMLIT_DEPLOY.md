# ⚡ Streamlit Cloud Quick Deploy (5 Minutes)

## 🎯 Get Your Live App in 5 Steps

### Step 1: Visit Streamlit Cloud
```
https://streamlit.io/cloud
```

### Step 2: Click "New App"
- Select "GitHub" repository source
- Select this repo: `PhytoVision-AI`
- Main file: `streamlit_app.py`

### Step 3: Advanced Settings
**IMPORTANT!** Set these:
- Requirements file: `requirements-streamlit.txt`
- Python version: 3.11

### Step 4: Click "Deploy"
Wait 3-5 minutes while Streamlit builds...

### Step 5: Your Live URL! 🎉
```
https://phytovision-ai-XXXXX.streamlit.app
```
